# Markdown 系统学习教程

## 第一部分：基础语法

### 1.标题 (Headings)
用于创建文档的章节结构。使用 # 号开头，有几个 # 就代表是几级标题，共支持六级。
```markdown
# 这是一级标题
## 这是二级标题
### 这是三级标题
#### 这是四级标题
##### 这是五级标题
###### 这是六级标题
```
**最佳实践：**
+ #和标题文字之间建议保留一个空格。
+ 一篇文档最好只有一个一级标题。
  
### 2.段落和换行 (Paragraphs & Line Breaks)
**段落**： 一个段落是由一个或多个连续的文本行组成。段落之间需要用一个
*空行*来分隔。   
**换行**： 如果只想在段落内换行（而不是开始一个新段落），可以在前一行的末尾输入两个或更多的空格或`<br>`，然后再按回车。

### 3.文本格式化 (Emphasis)
用于强调文本。

```markdown
*这是斜体*
_这也是斜体_

**这是粗体**
__这也是粗体__

***这是粗斜体***
___这也是粗斜体___

~~这是删除线~~
<u>这是借用url实现的下划线</u>
```

### 4.列表 (Lists)
分为无序列表和有序列表。

**无序列表**  
使用 *、+ 或 - 作为列表标记。

```markdown
- 项目一
- 项目二
  - 子项目二点一 (通过缩进创建)
  - 子项目二点二
- 项目三

* 同样是无序列表
+ 这也是
```

**有序列表**  
使用数字加一个英文句点。

```markdown
1. 第一项
2. 第二项
3. 第三项
   1. 子项 3.1 (通过缩进创建)
   2. 子项 3.2
```
**注意**：有序列表前的数字并不重要，即使全部写成 1.，Markdown也会自动渲染成正确的1, 2, 3... 序列。

### 5.链接 (Links)
```markdown
[链接显示的文字](链接地址 "可选的悬停标题")
[点击这里访问谷歌](https://www.google.com "访问 Google")
[这是一个没有标题的链接](https://www.github.com)
```

### 6.图片 (Images)
语法和链接非常相似，只是在前面多一个感叹号 !。
```markdown
![图片的替代文字](图片地址 "可选的悬停标题")
![Markdown Logo](https://markdown.com.cn/assets/img/markdown-logo-2.png "Markdown 标志")
```

### 7.引用 (Blockquotes)
用于引用他人的文字或名言。使用 > 符号。
```markdown
> 这是一段引用。
> > 引用可以嵌套。
> #### 引用里也可以使用其他 Markdown 语法
> - 比如列表
```

### 8.代码 (Code)
**行内代码**   
使用一对反引号``包裹。

```markdown
在 JavaScript 中，可以使用 `console.log()` 来打印日志
```

**代码块**  
使用三对反引号``````包裹，并可以在开头指定语言以实现语法高亮。
```markdown
{```python
def hello_world():
    print("Hello, Markdown!")

hello_world()```}
```

### 9.分隔线 (Horizontal Rules)
在一行中使用三个或更多的 *、- 或 _ 来创建一条分隔线。
```markdown
---
***
___
```

## 第二部分：高级语法与扩展
这些语法在标准 Markdown 中不一定存在，但在现代 Markdown 编辑器（如 Typora、VS Code、Obsidian）中被广泛支持，称为 GFM (GitHub Flavored Markdown)。

### 10.表格 (Tables)
使用|分隔不同的单元格，使用-分隔表头和表体，在分隔行中使用:来控制对齐方式。
```markdown
| 姓名   | 年龄 | 城市     |
| :----- | :--: | -------: |
| 张三   |  25  | 北京     |
| 李四   |  30  | 上海     |
| 王五   |  22  | 广州     |
:----- 表示左对齐（默认）
:--: 表示居中对齐
-----: 表示右对齐
```

### 11.任务列表 (Task Lists)
在列表项前加上方框[]或打勾方框[x]。
```markdown
- [x] 完成 Markdown 基础学习
- [ ] 学习高级语法
- [ ] 找一篇文档来练习
```
### 12.删除特殊字符功能 (Escaping)
如果想在文档中显示 Markdown 的特殊字符（如 *, #, _），而不是让它们被解析，可以在字符前加上反斜杠 \。
```markdown
我想显示 \*星号\* 而不是斜体。
我想显示一个井号 \# 而不是标题。
```

### 13.脚注 (Footnotes)
语法：
```markdown
这是一个需要脚注的句子。[^1]
这是另一个需要脚注的地方。[^note]
[^1]: 这是第一个脚注的解释。
[^note]: 这是另一个脚注，可以使用文本标签。
```
